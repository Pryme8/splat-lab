Sculpt language reference 
// primitives (centered at origin)
sphere(r)  box(x, y, z)  roundBox(x, y, z, r)
torus(R, r)  cylinder(r, halfH)  capsule(halfH, r)
octahedron(s)  gyroid(freq, wall)  // gyroid is infinite: intersect it

// booleans (k > 0 gives a smooth blend of width k)
union(a, b, ...)        a.add(b, k)
subtract(a, b, ...)     a.sub(b, k)
intersect(a, b, ...)    a.and(b, k)
smoothUnion(k, a, b, ...)
smoothSubtract(k, a, b)  smoothIntersect(k, a, b)

// transforms and modifiers (chainable)
.at(x, y, z)  .rot(degX, degY, degZ)  .scale(s)
.twist(k)  .bend(k)  .mirror('xz')
.repeat(sx, sy, sz, count)   // spacing 0 = no repeat on that axis
.round(r)  .shell(t)  .displace(amp, freq)  .noise(amp, freq)

// color
.color('#e8a33d')  .color(r, g, b)
.paint((x, y, z) => hsl(h, s, l))
hsl(h, s, l)  mix(a, b, t)
bounds(r)   // search radius, default 4

// the last expression (or a return) is the shape.

Renderer
Train

Every source becomes the same thing: oriented surface elements with a position, three axes, three radii, a color and an opacity. Untrained, each renderer just converts those elements into its own primitive. Training is what the papers actually do: it optimizes the primitives until renders from many cameras match the teacher. Training runs on WebGPU in your browser; files stay on your machine.
